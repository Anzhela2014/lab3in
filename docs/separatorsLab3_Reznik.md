# Введение

Markdown — это легкий язык разметки, созданный для написания максимально читаемого и удобного для правки текста, который легко конвертируется в HTML.

---

# Основные возможности Markdown

Язык поддерживает простое форматирование текста: создание заголовков, списков, добавление ссылок, изображений и выделение текста (жирный, курсив).

***

# Пример форматирования

Вы можете использовать дефисы, звездочки или нижние подчеркивания для создания горизонтальных линий, разделяющих логические блоки вашего документа.
